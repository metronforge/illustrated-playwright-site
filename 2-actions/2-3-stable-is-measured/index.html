Stable is a count of equal boxes

2.3 · Actions · locator.click()

How a click decides that the element has stopped moving.

Before a click, Playwright checks stable first 1. Then it checks visible, enabled and not inert. The element and its parents must have no inert attribute. If the element still moves, the other three states are not checked in that attempt.

To check stable, Playwright measures the element’s box on each animation frame 2. The box is the top, left, width and height. The first box is only stored. Each next equal box adds one to a count. The check passes when the count reaches the required value.

Source ↗

If the box changes, the check fails at once 3. The call log says element is not stable, and the click tries again. The new attempt starts a new check with no stored box. An element that never stops moving fails until the timeout.

Chromium, Firefox and WebKit use a count of one by default 4. The first box is only stored, so one comparison needs two equal boxes.

What you see in the call log

  • waiting for element to be visible, enabled and stableThe checks start here; this does not prove they passed. The message omits the not inert check.
  • element is not stableThe box changed between two frames. Visible, enabled and not inert were not checked in this attempt.
  • retrying click actionA new attempt. It starts a new stability check with no stored box.
  • element is visible, enabled and stableAll four states passed. The click goes on to scrolling and the hit target check.
