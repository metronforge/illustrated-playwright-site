How to read

Each spread explains one part of Playwright. Use the figure and notes together.

Layers

  • testYour test calls Playwright and checks results.
  • runnerThe runner loads tests, manages fixtures, and starts workers.
  • clientClient objects turn API calls into channel messages.
  • protocolThe protocol defines messages between the client and server.
  • serverThe server runs actions and controls browser adapters.
  • pageInjected scripts inspect elements inside the page.
  • browserThe browser renders pages and processes input.
