Expectations and results

Choose what a wait repeats, then read what the saved report can tell you.

A locator assertion repeats a server check; expect.poll repeats your value-producing function in the test worker. Positive toPass repeats the whole block when it throws, including earlier requests or actions. Reporters receive run events, and merge-reports replays saved events without running tests again. Start with 5.1 to separate the loops, then read 5.2 for reporting and the merge result.
