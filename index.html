The Illustrated Playwright

An animated reference to how Playwright works inside. Each spread explains one concept with a moving diagram, a few short paragraphs and code. Every claim is checked against the Playwright source.

Playwright is created by Microsoft and contributors. This book is an independent analysis of the source code at tag v1.64.1, not official documentation.
